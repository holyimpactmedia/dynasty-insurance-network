# Task 1: Toolchain

Part of [docs/plan.md](../../../plan.md). Read its Global Constraints first.

**Goal:** install the pinned Neon, Better Auth and Drizzle packages, add the db and auth scripts, make `pnpm lint` actually run, and remove the stale `bun.lock`. No behavior changes.

**Files:**
- Modify: `package.json`, `pnpm-lock.yaml` (regenerated by pnpm)
- Create: `eslint.config.mjs` (copied from redesign)
- Delete: `bun.lock`

**Interfaces:**
- Consumes: nothing.
- Produces: `pnpm lint`, `pnpm db:generate`, `pnpm db:migrate`, `pnpm db:verify`, `pnpm auth:bootstrap` script names (the scripts they run arrive in Tasks 4 and 5); the packages every later task imports.

**Why:** `pnpm-lock.yaml` is the lockfile Vercel uses (`vercel.json` runs `pnpm install`; `packageManager: pnpm@10.17.1`). `bun.lock` has not changed since the first commit and lacks vitest. The redesign's caret ranges would resolve `better-auth` to 1.7.x, which the redesign never tested, and its tested 1.6.20 sits inside GHSA-qq9h-g4jm-xgf3; 1.6.33 is the maintained 1.6 line.

- [ ] **Step 1: Add the runtime packages, pinned exactly**

```bash
pnpm add -E better-auth@1.6.33 @better-auth/drizzle-adapter@1.6.33 drizzle-orm@0.45.2 pg@8.22.0
```

Expected: pnpm finishes without errors. If it prints "Ignored build scripts" for esbuild, that is expected (pnpm 10 skips build scripts by default) and harmless for these packages.

- [ ] **Step 2: Add the dev packages, pinned exactly**

```bash
pnpm add -E -D drizzle-kit@0.31.10 @types/pg@8.20.0 tsx@4.22.4 eslint@9.39.4 eslint-config-next@16.0.10
```

- [ ] **Step 3: Confirm the versions landed exactly**

```bash
pnpm list better-auth @better-auth/drizzle-adapter drizzle-orm pg drizzle-kit @types/pg tsx eslint eslint-config-next zod --depth 0
```

Expected: `better-auth 1.6.33`, `@better-auth/drizzle-adapter 1.6.33`, `drizzle-orm 0.45.2`, `pg 8.22.0`, `drizzle-kit 0.31.10`, `@types/pg 8.20.0`, `tsx 4.22.4`, `eslint 9.39.4`, `eslint-config-next 16.0.10`, `zod 3.25.76`. Any other version: stop and fix the pin.

- [ ] **Step 4: Add the scripts**

In `package.json`, replace:

```json
    "test": "vitest run",
    "test:watch": "vitest"
  },
```

with:

```json
    "test": "vitest run",
    "test:watch": "vitest",
    "db:generate": "drizzle-kit generate",
    "db:migrate": "drizzle-kit migrate",
    "db:verify": "tsx --env-file-if-exists=.env.local scripts/verify-neon-schema.ts",
    "auth:bootstrap": "tsx --env-file-if-exists=.env.local scripts/bootstrap-auth-users.ts"
  },
```

(`--env-file-if-exists` is a Node 22 flag that tsx passes through, so the scripts read `.env.local` without printing it.)

- [ ] **Step 6: Run lint and record the baseline**

```bash
pnpm lint
```

Expected: exit 0. If it reports errors:
- In a legal-frozen file (see Global Constraints): do NOT edit the file. Turn the specific rule off in the `rules` block of `eslint.config.mjs` with a one-line comment naming the file and why, so the frozen copy stays byte-identical.
- In any other file: fix the code if the fix is mechanical and behavior-neutral; otherwise turn the rule off in the config with a comment and note it in `docs/build-log.md` (create the file if missing) as a follow-up.
Re-run until exit 0. Record the final rule list in the commit message.
